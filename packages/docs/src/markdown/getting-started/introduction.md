## What is QWindow

QWindow is a Quasar component package for building floating, movable, and resizable window panels.
Use it for dashboards, tool palettes, inspectors, workspace-style UIs, and places where users need
to keep multiple pieces of context visible.

The v3 migration focuses on Vue 3, Quasar 2, TypeScript, and a modern Teleport-based floating
implementation.

## Components

- `QWindow` provides the floating/embedded panel, title bar, menu actions, move behavior, resize
  handles, and content area.
- The app extension registers QWindow and its stylesheet in Quasar CLI Vite projects.
